## 正文草稿

```text
最近做了一个有点可爱的开源小工具：pet-desk-moodBytoken。

它的想法很简单：
当我在 Codex / Claude Code 里写代码时，本地 agent 的 token 用量会慢慢上升。以前这个数字不够直观，所以我把它变成了一只桌面小狗的心情。

用量低的时候，小狗精神站着。
用量上来以后，它会开始疲惫、坐下、塌下去。
快到极限时，它会直接趴倒。

重点是：它不是把宠物变透明、变灰或者加滤镜，而是真的切换五套不同的表情和姿态 sprite。

我希望它最后的使用方式足够简单：
在 Codex / Claude Code 里输入 /petdesk，就能直接唤醒桌宠。

目前已经支持：
- 本地读取 Codex 原生用量百分比
- Claude Code / Codex transcript token 估算
- token 百分比进度条显示
- 默认宠物 aka-shiba
- 自定义宠物 mood sprites
- 本地优先，不上传 prompt 和 response

项目还在继续打磨安装体验和跨平台 release。如果你也喜欢 AI 编程、桌宠、开源小工具，可以来 GitHub 看看。

Repo：
https://github.com/BlueWhalexh/pet-desk-moodBytoken
```
